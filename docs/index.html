Protocol Architecture

Two dedicated TCP streams guarantee responsive drawing even under heavy network load.

1

mDNS Discovery

Avahi publishes _drawpad._tcp with protocol version 2 and host UUID.

2

Control Plane (TCP)

Bidirectional JSON packets for stroke vectors, display descriptors, ping/pong, and canvas clearing.

3

Video Plane (TCP)

H.264 stream with SPS/PPS parameter set packets and AVCC length-prefixed video envelopes.

// Linux / Omarchy Host Architecture
Hyprland Output -> FFmpeg (libx264) -> AVCC Parser
└─ Video TCP -> iPad AVSampleBufferDisplayLayer
iPad Touch Vectors -> Control TCP -> DrawingState
└─ tiny-skia -> Wayland wlr-layer-shell Overlay

CLI Reference

Manage the background daemon directly from your terminal or scripts.

Command Description
skeldri Run the Skeldri daemon interactively in foreground
skeldri status Show live connection status, active monitor, and stroke count
skeldri status --json Output machine-readable JSON status (for bar plugins & scripts)
skeldri clear Clear all annotations from host overlay and iPad screen
skeldri toggle Toggle annotation overlay visibility without erasing strokes
skeldri select-display <id> Switch mirrored video output to the specified display ID
skeldri stop Gracefully stop the background daemon
