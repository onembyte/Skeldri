# Skeldri branding

Skeldri's flowing rune mark abstracts Ansuz, representing communication, into the open angle of Kenaz, representing craft. Three parallel ribbons travel through a single controlled turn: a visual shorthand for responsive input moving between iPad and Mac.

The application icon uses a cyan-to-cobalt ribbon on a deep midnight field. The macOS menu-bar asset reduces the same silhouette to a monochrome vector template so AppKit can adapt it to the current menu-bar appearance and keep it legible at small sizes.

The artwork is original rune-inspired branding, not a claim of a historically attested bindrune or a definitive translation of historical rune meanings.
