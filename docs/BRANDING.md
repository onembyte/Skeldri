# Skeldri branding

Skeldri's mark places two independent rune-inspired forms side by side: Ansuz for communication and Kenaz for craft. Their separation represents the Mac and iPad, while the shared visual treatment connects them as one tool.

The application icon uses a rough, hand-hewn charcoal treatment on a warm bone background. The macOS menu-bar asset is intentionally simplified into a monochrome vector template so AppKit can adapt it to the current menu-bar appearance and keep it legible at small sizes.

The artwork is original rune-inspired branding, not a claim of a historically attested bindrune or a definitive translation of historical rune meanings.
