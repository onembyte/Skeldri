# Skeldri Privacy Policy

Last updated: August 12, 2026

Skeldri does not collect, retain, sell, or share personal data. It contains no advertising, analytics, telemetry, accounts, cloud backend, or third-party runtime SDKs.

When the user approves a connection, the Mac sends the selected display image directly to the approved iPad on the same local network. Drawing and trackpad commands travel directly between those devices. This content is processed transiently to provide the requested feature; Skeldri does not upload it to the developer or store it as a recording.

Skeldri stores only local preferences such as the selected drawing tool and trackpad sensitivity. These preferences remain on the device and can be removed by deleting the app.

The Mac requests Screen Recording access for mirroring and Accessibility access only when the user enables trackpad control. The iPad requests Local Network access for Bonjour discovery and device-to-device communication. Skeldri does not request camera, microphone, location, contacts, or photo-library access.

Questions about this policy should be sent through the private contact method provided on Skeldri's App Store product page. Before submission, the owner must publish this policy at a public HTTPS URL and insert the final support contact.
