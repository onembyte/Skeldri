## iPad description

Skeldri turns your iPad into a responsive drawing surface and optional trackpad for your own Mac. Discover a nearby Mac automatically, approve the connection on the Mac, mirror one display, and annotate it with your finger—no Apple Pencil, account, cloud service, or manual IP address required.

Use pen, highlighter, color, thickness, stroke eraser, undo, clear, and fast display switching. Trackpad mode supports pointer movement, clicks, dragging, two-finger scrolling, and zoom. Screen video and low-latency controls travel directly between your devices on the local network.

Requires the Skeldri companion app on a Mac on the same local network.

## Mac description

Skeldri is the Mac companion for the Skeldri iPad app. It securely waits in the menu bar, requires explicit approval for every iPad session, streams only the selected display, and renders synchronized annotations in a transparent click-through overlay.

Skeldri excludes its own interface and annotation overlay from capture, keeps normal mouse and keyboard use available, and stops expensive capture and encoding when no approved iPad is connected. Optional trackpad control remains behind macOS Accessibility consent.

Requires the Skeldri app on an iPad on the same local network.
